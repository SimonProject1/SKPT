# Bayer PLT Tools

## GitHub Pages
1. Den Inhalt dieser ZIP-Datei direkt in den Hauptordner des Repositorys hochladen.
2. Unter **Settings > Pages** die Quelle **Deploy from a branch** wählen.
3. Branch **main** und Ordner **/(root)** einstellen.
4. Das Feld **Custom domain** leer lassen, sofern keine eigene Domain verwendet wird.

Die Startseite verlinkt auf den Analogsignal-Rechner und den P+F-Rechner.

## P+F-Rechner
Der Rechner verwendet die lineare Funktion `Y = K × X + Nullpunkt` und bestimmt K sowie den Nullpunkt aus zwei Wertepaaren.
